# 🤖 学习通全能助手 

![Version](https://img.shields.io/badge/version-v5.1.0-blue)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

一款专为学习通（超星/尔雅）打造的浏览器自动化扩展程序。彻底解放双手，告别繁琐的点击与等待！专为学习通（超星）用户设计的高效题库管理与自动答题工具。

## DeepSeek V4.1 Flash（本 fork 新增）

1. 下载此仓库并解压，在 Chrome `chrome://extensions` 中开启开发者模式、加载未打包扩展，选择包含 `manifest.json` 的目录。停用旧版，刷新已打开的超星页面。
2. 在助手的「答题」页选择 **DeepSeek V4.1 Flash**，点击「DeepSeek API 设置」，输入自己的 Key 并保存。默认模型 ID 为 `deepseek-flash`，接口固定为 DeepSeek 官方 HTTPS 地址。
3. 进入实际题目页后点击「开启自动答题」。扩展在每个匹配的子框架中自动扫描，逐题请求并填写单选、多选、判断、普通文本填空或简答；不需要导入 Excel。
4. 检查每题下方的答案和解析后手动提交。暂停后不会填入仍在请求中的答案；错误不会每两秒反复重试，停止后重新开启即可重试。

Key 仅保存在可信扩展会话中，重启浏览器或重新加载插件后需要重填。图片题、不可见内容、富文本编辑器的独立 iframe 暂不自动处理；答案仍需人工核对。AI 模式只处理当前页，不自动翻页或提交。Excel 模式保留原有行为。

开发验证：Node.js 20.19+，`npm install` 后运行 `npm test`，覆盖乱序选项、多选取消旧选项、填空事件、暂停、请求去重、发送方权限和异常响应。

## ✨ 核心功能 (v5.0 全新升级)

### 📺 智能排队刷课 (降维打击版)
* **精准识别**：穿透复杂的网页嵌套框架，直接提取底层数据，精准锁定真实的未完成任务。
* **自动执行**：视频与图文 PPT 智能排队，完成一个自动接管下一个，互不干扰。
* **视频极速静音**：默认 2.0x 倍速播放（支持手动切换），自动静音，自带防暂停机制，无视切屏或失焦限制。
* **暴力文档翻页**：光速滑到底部，破解各类隐藏滚动条的打卡限制。

### ⏭️ 无感连播与智能跳过
* **跳过已完成**：透视底层数据，已变绿的任务点绝对不重复刷。
* **测验免打扰**：遇到章节测验自动放行，绝不卡住学习进度。
* **强穿拦截弹窗**：所有任务处理完毕后自动点击“下一节”，并在 500 毫秒内自动粉碎“还有任务点未完成”的警告弹窗，强制通行。

### ⛏️ 题库抓取与自动答题
* **题目抓取**：一键遍历并抓取当前页面的所有题目。
* **多格式导出**：支持将抓取的题库一键导出为 Excel 或 Word 格式，方便日后复习。
* **本地自动答题**：支持上传自定义 Excel 题库，设定答案列后，自动匹配并填写答案。

## 🚀 使用指南

扩展程序共分为三大独立运行的模块，界面清爽，互不干扰：

1.  **📺 刷课模块**：进入带有视频或文档的章节页面，打开面板，点击“**▶ 一键完成页面任务**”。你可以去喝杯咖啡，它会自动看完当前页并跳到下一章。
2.  **⛏️ 抓取模块**：在测验页面，点击“**▶ 开始自动抓取**”，配合系统的翻页功能收集题目，完成后点击导出。
3.  **⚡ 答题模块**：进入考试页面，点击“**📂 上传题库**”导入你的 Excel 答案文件，选好答案所在的列，最后点击“**⚡ 开启自动答题**”。
